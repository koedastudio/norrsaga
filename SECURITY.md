# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/koedastudio/norrsaga/security/advisories/new),
not in public issues. You should get an initial response within a week, and a
fix ships before details are published.

This covers the Norrsaga apps (Android Automotive OS, iOS, macOS) and the
iOS push relay. The ebook narrator has its own policy in
[norrsaga-narrator](https://github.com/koedastudio/norrsaga-narrator/blob/main/SECURITY.md).

## Supported versions

Only the latest release of each app receives security fixes.
